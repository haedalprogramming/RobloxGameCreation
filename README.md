# RobloxGameCreation
로블록스로 배우는 게임 제작 기초

# Goal
게임 제작의 기초를 이해하고 로블록스를 이용하여 기초 게임을 만드는 실습을 한다.

# Target
 - 게임개발의 기초를 알고 싶은 사람
 - 로블록스로 게임을 제작해 보고 싶은 사람
